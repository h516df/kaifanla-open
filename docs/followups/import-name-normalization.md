## 缺陷与最小修复

已有菜品“招牌面”，导入预览把菜名编辑为“招牌面 ”。旧合并代码用未修剪名称查重，保存时却调用 trim，最终出现两个完全相同的保存名称；已有价格和未知价格两种情况都会发生，同批导入也可重复。

用 DraftDish.savedName 统一合并匹配、初次预览匹配和保存时的 trim。保留旧数据原样，不清历史重复，不折叠大小写、全半角或内部空格；本补丁没有 UI 布局/组件改动。人工编辑后的标签即时重算不在本次范围，最终保存仍按实际规范名称核对。
