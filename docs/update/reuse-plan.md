# App 内更新最小适配

当前应用没有更新器。正式包名为 com.jintianchishenme.app，源码 namespace 不可用作安装身份。原仓库为 private，现有 v2.2 APK 也在该私有仓库，现有脚本没有配置公开发行镜像。

MealUpdateChannel.Pending 默认无网络目标，不启用检查、下载或安装。只有确认公开发行目标和原签名证书的公开 SHA-256 指纹后才能配置；不使用令牌，不改变源码仓库可见性，不自动创建仓库。正式版本号仍需递增，debug 包不得走正式更新。

计划最小复用同所有者 h516df/shicang 的 Apache-2.0 更新器，保留许可证与修改说明：
- 默认手动检查；用户明确开启提醒后才进行前台匿名检查，24小时限频；仅请求版本说明，不上传菜单、历史、昵称或照片。
- 用户点击后下载，显示进度；离开设置页仍保留状态，取消后保留当前应用数据。
- 下载大小、SHA-256、API digest、包名、递增版本号、原签名和 ABI 全部校验，安装前再次校验。
- 未授权安装来源时只解释并引导系统设置，授权返回续接校验/系统安装；最终安装由用户在系统界面确认，不能静默安装。
- 不复制留册旧授权清理，因为本应用无此迁移。已按留册固定提交 01a783076e50e2d89366188144a43db5bdf1d9b8 最小移植安全核心/状态机，来源和 Apache-2.0 许可证保存在 third_party/shicang-updater。

此文档和配置占位不代表更新功能已接通；匿名读取私有 Releases 不可行，发行源选择仍待确认。公开发行内容仅包括经确认的安装包与版本/校验说明，不包括源码、个人数据或签名私钥。

当前已接入设置入口与应用生命周期，但发行源未配置时明确显示“发行源待配置”，无检查/下载/安装按钮；HTTP 层也独立拒绝任何连接。该待配置状态不能作为已可更新的正式版本交付。
